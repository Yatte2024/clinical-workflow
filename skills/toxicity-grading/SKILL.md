# CTCAE v5.0 Grading Reference

## Grade Definitions

| Grade | Severity | Clinical Meaning |
|-------|----------|-----------------|
| 0 | Normal | Within normal limits (not an official CTCAE grade, used in shift tables) |
| 1 | Mild | Asymptomatic or mild symptoms; clinical or diagnostic observations only; intervention not indicated |
| 2 | Moderate | Minimal, local, or noninvasive intervention indicated; limiting age-appropriate instrumental ADL |
| 3 | Severe | Severe or medically significant but not immediately life-threatening; hospitalization or prolongation indicated; disabling; limiting self-care ADL |
| 4 | Life-threatening | Life-threatening consequences; urgent intervention indicated |
| 5 | Death | Death related to adverse event |

**ADL Reference:**
- Instrumental ADL: cooking, shopping, using telephone, managing money
- Self-care ADL: bathing, dressing, feeding self, using toilet, taking medications

## Applying CTCAE Grades in DuckDB

### When ATOXGR Is Available (Pre-Derived)

If the ADLB dataset has `ATOXGR` (analysis toxicity grade), use it directly:

```sql
-- Worst post-baseline toxicity grade per subject per parameter
SELECT adsl.TRT01A, adlb.PARAMCD,
       MAX(CAST(adlb.ATOXGR AS INTEGER)) as WORST_GRADE,
       COUNT(DISTINCT adlb.USUBJID) as N_SUBJ
FROM adlb
JOIN adsl ON adlb.USUBJID = adsl.USUBJID
WHERE adsl.SAFFL = 'Y' AND adlb.ABLFL IS NULL
  AND adlb.ATOXGR IS NOT NULL
GROUP BY adsl.TRT01A, adlb.PARAMCD, adlb.USUBJID
```

### When ATOXGR Is NOT Available (Compute From Values)

Use ULN (A1HI) and LLN (A1LO) from the ADLB record to grade:

```sql
-- Grade ALT values using CTCAE criteria
SELECT USUBJID, AVISIT, AVISITN, AVAL, A1HI as ULN,
  CASE
    WHEN AVAL IS NULL OR A1HI IS NULL OR A1HI = 0 THEN NULL
    WHEN AVAL <= A1HI THEN 0
    WHEN AVAL <= 3.0 * A1HI THEN 1
    WHEN AVAL <= 5.0 * A1HI THEN 2
    WHEN AVAL <= 20.0 * A1HI THEN 3
    ELSE 4
  END as CTCAE_GRADE
FROM adlb
WHERE PARAMCD = 'ALT' AND ANL01FL = 'Y'

-- Grade Hemoglobin (uses absolute values, not multiples of LLN)
SELECT USUBJID, AVISIT, AVAL,
  CASE
    WHEN AVAL IS NULL THEN NULL
    WHEN AVAL >= 10.0 THEN 1  -- assuming LLN > 10
    WHEN AVAL >= 8.0 THEN 2
    WHEN AVAL > 0 THEN 3      -- Grade 4 requires clinical context
    ELSE NULL
  END as CTCAE_GRADE
FROM adlb
WHERE PARAMCD = 'HGB' AND ANL01FL = 'Y' AND AVAL < A1LO

-- Grade Platelets (absolute thresholds)
SELECT USUBJID, AVISIT, AVAL,
  CASE
    WHEN AVAL IS NULL THEN NULL
    WHEN AVAL >= 75.0 THEN 1
    WHEN AVAL >= 50.0 THEN 2
    WHEN AVAL >= 25.0 THEN 3
    ELSE 4
  END as CTCAE_GRADE
FROM adlb
WHERE PARAMCD = 'PLAT' AND ANL01FL = 'Y' AND AVAL < A1LO

-- Grade ANC/Neutrophils (absolute thresholds)
SELECT USUBJID, AVISIT, AVAL,
  CASE
    WHEN AVAL IS NULL THEN NULL
    WHEN AVAL >= 1.5 THEN 1
    WHEN AVAL >= 1.0 THEN 2
    WHEN AVAL >= 0.5 THEN 3
    ELSE 4
  END as CTCAE_GRADE
FROM adlb
WHERE PARAMCD = 'ANC' AND ANL01FL = 'Y' AND AVAL < A1LO

-- Grade Creatinine (multiples of ULN)
SELECT USUBJID, AVISIT, AVAL, A1HI as ULN,
  CASE
    WHEN AVAL IS NULL OR A1HI IS NULL OR A1HI = 0 THEN NULL
    WHEN AVAL <= A1HI THEN 0
    WHEN AVAL <= 1.5 * A1HI THEN 1
    WHEN AVAL <= 3.0 * A1HI THEN 2
    WHEN AVAL <= 6.0 * A1HI THEN 3
    ELSE 4
  END as CTCAE_GRADE
FROM adlb
WHERE PARAMCD = 'CREAT' AND ANL01FL = 'Y'
```

## Grading Conventions

- **ULN** = Upper Limit of Normal → `A1HI` in ADaM, `--STNRHI` in SDTM
- **LLN** = Lower Limit of Normal → `A1LO` in ADaM, `--STNRLO` in SDTM
- **×ULN** = multiples of upper limit (e.g., 3.0×ULN = 3 × A1HI)
- **Grade 0** = within normal limits (not official CTCAE, used in shift tables)
- If ATOXGR/BTOXGR present in ADLB, use them directly (pre-derived by sponsor)
- If no reference range is available (A1HI/A1LO is NULL), grading cannot be performed — flag for clinical review
- Some parameters use absolute thresholds (hemoglobin, platelets, ANC, electrolytes) rather than multiples of ULN/LLN
- Hematology tests grade in the LOW direction (below LLN); hepatic tests grade in the HIGH direction (above ULN)
- Electrolytes can grade in BOTH directions (hyper- and hypo-)

## Grade Shift Table Pattern

A common safety analysis: how did each subject's grade shift from baseline to worst post-baseline?

```sql
-- Simplified grade shift for ALT
WITH baseline AS (
  SELECT USUBJID,
    CASE
      WHEN AVAL <= A1HI THEN 0
      WHEN AVAL <= 3.0 * A1HI THEN 1
      WHEN AVAL <= 5.0 * A1HI THEN 2
      WHEN AVAL <= 20.0 * A1HI THEN 3
      ELSE 4
    END as BL_GRADE
  FROM adlb
  WHERE PARAMCD = 'ALT' AND ABLFL = 'Y'
),
worst AS (
  SELECT USUBJID,
    MAX(CASE
      WHEN AVAL <= A1HI THEN 0
      WHEN AVAL <= 3.0 * A1HI THEN 1
      WHEN AVAL <= 5.0 * A1HI THEN 2
      WHEN AVAL <= 20.0 * A1HI THEN 3
      ELSE 4
    END) as WORST_GRADE
  FROM adlb
  WHERE PARAMCD = 'ALT' AND ABLFL IS NULL AND ANL01FL = 'Y'
  GROUP BY USUBJID
)
SELECT adsl.TRT01A, b.BL_GRADE, w.WORST_GRADE,
       COUNT(DISTINCT b.USUBJID) as N_SUBJ
FROM baseline b
JOIN worst w ON b.USUBJID = w.USUBJID
JOIN adsl ON b.USUBJID = adsl.USUBJID
WHERE adsl.SAFFL = 'Y'
GROUP BY adsl.TRT01A, b.BL_GRADE, w.WORST_GRADE
ORDER BY adsl.TRT01A, b.BL_GRADE, w.WORST_GRADE
```
